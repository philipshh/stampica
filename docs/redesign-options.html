Stampica — redesign directions

Three directions for the homepage and the creation page. The logo stays in all of them. Each mock shows the home hero (left) and the editor (right) with the simplified control model: Effects → Palette → Size, with an Advanced toggle.

Option A

Paper Studio

Warm paper-white, ink black, one vermillion accent, serif display (Fraunces). Feels like a real print shop: posters as physical objects with tape and shadows, grid-paper editor canvas. Light UI stands out among dither tools (they are all dark) and photographs beautifully for Instagram. Best fit for selling physical + digital prints as a boutique product.

Option B

Darkroom

Keeps the dark identity but modernizes it: near-black with soft elevated surfaces, a single electric accent (lime shown; could be any), Space Grotesk headings, mono microcopy. The editor becomes a focused tool: thin icon rail, poster glowing center-stage, a Ladybug-style effect filmstrip along the bottom, and one compact properties panel. Lowest-risk evolution of what exists.

Option C

Riso Pop

Leans into the riso-print heritage of dithering: flat riso-ink colors (blue, fluorescent pink, yellow), chunky Archivo type, hard 2px borders and offset shadows, sticker badges, rotated cards. Loud, young, extremely shareable — the brand itself looks like the posters it makes. Editor keeps the same simple three-step panel but in the pop style.
